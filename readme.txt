Very simple drawing tool for the console.

## Usage

You can pipe a file to the program or just run it and start drawing.

It will output the drawing to the console.

## Commands

Any unicode character you enter will be selected as the drawing character.

- `Ctrl+C` to quit without outputting the drawing.
- `F10` to quit and output the drawing.
- `F1` Pencil tool.
- `F2` Line tool.
- `F3` Rectangle tool.
- `F4` Circle tool.
- `F5` Fill tool.
- `Enter` Text tool.
